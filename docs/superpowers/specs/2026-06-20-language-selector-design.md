# Language Selector — Design Spec
_Date: 2026-06-20_

## Overview

Add a flag-based language selector to the navigation header so guests can read the wedding website in their preferred language. The selected language persists across sessions via `localStorage`. Translations are generated once using the DeepL API and stored as static JSON files.

## Translation JSON Structure

Flat key-value format, namespaced by page/component. `locales/en-US.json` (inside `wedding_website/`) is the single source of truth for all website text. The example below is illustrative — during implementation, every piece of human-readable text on every page must be extracted into a key.

```json
{
  "nav.home": "Home",
  "nav.story": "Our Story",
  "nav.rsvp": "RSVP",
  "nav.details": "Details",
  "nav.photos": "Photos",
  "nav.login": "Login",
  "nav.logout": "Logout",

  "home.title": "are getting married!",
  "home.cta.rsvp": "RSVP Now",
  "home.cta.details": "View Details",
  "home.welcome.heading": "Join Us for Our Special Day",
  "home.welcome.body": "We're thrilled to invite you to celebrate our wedding with us. Your presence would mean the world to us as we begin this new chapter together.",
  "home.welcome.body2": "Please take a moment to RSVP and let us know if you can join us. We can't wait to celebrate with you!",
  "home.card.story.heading": "Our Story",
  "home.card.story.body": "Learn about our journey together",
  "home.card.details.heading": "Event Details",
  "home.card.details.body": "Venue, schedule, and accommodation info",
  "home.card.photos.heading": "Share Photos",
  "home.card.photos.body": "Upload and view wedding photos",

  "story.heading": "Our Story",

  "rsvp.heading": "RSVP",

  "details.heading": "Wedding Details",
```

**Not translated (stays hardcoded):** couple names ("João & Zuza"), wedding date ("July 3, 2027"), venue address ("Lesna 19, Lesna"), and nav link labels "RSVP" (universally understood).

## `lib/i18n.ts` — Context & Hook

- On mount, reads `localStorage` for a saved locale code; defaults to `'en-US'`
- Dynamically imports the matching JSON file (e.g., `locales/cs.json`)
- Exposes `t(key: string): string` — returns the translated string; falls back to the `en-US` value if the key is missing in the current locale
- Exposes `locale: string` and `setLocale(code: string): void` — switching locale saves to `localStorage` immediately

## `components/LanguageProvider.tsx`

A `'use client'` component that wraps `layout.tsx` children with the language context. No server-side logic needed.

```tsx
// layout.tsx
<LanguageProvider>
  <Navigation />
  <main>{children}</main>
</LanguageProvider>
```

## Navigation Dropdown UI

- **Closed state:** `🇺🇸 EN-US ▼` pill button, right side of nav bar, immediately before the Login/user section
- **Open state:** A dropdown panel (210px wide, rose-accented) lists all 13 languages as flag + native name. The current language is highlighted with a rose left-border and "Current" label.
- Clicking outside the dropdown closes it.
- On mobile (hamburger menu): language selector is included in the mobile menu (implementation detail left to the plan).

## `scripts/generate-translations.ts`

- Reads `locales/en-US.json` as the source
- For each target locale file:
  - Loads existing locale JSON (if it exists)
  - Compares each key: only sends to DeepL if the key is **missing** or the English source value has **changed** since last generation
  - Tracks the English source value alongside each translation in a sidecar file (`locales/.cache.json`) to detect changes
  - Writes updated locale JSON
- Requires `DEEPL_API_KEY` environment variable (free tier is sufficient)
- Run with: `npx ts-node scripts/generate-translations.ts`

## Key Constraints

- No new runtime dependencies (no i18n library)
- No URL routing changes (`/en/`, `/pt/` paths are not used)
- `locales/en-US.json` is the only file humans edit for content changes; other locale files are generated
- Manual corrections to generated locale files are preserved across re-runs (the smart cache detects only source-changed keys)
- DeepL free tier (500k chars/month) is well within budget for this site
